មាគ៌ាឆ្ពោះទៅកាន់អាជីពជោគជ័យ (Career Paths)

ស្វែងយល់ពីជំហានអភិវឌ្ឍន៍ពីថ្នាក់វិទ្យាល័យ ថ្នាក់សាកលវិទ្យាល័យ រហូតដល់ទីផ្សារការងារតាមមុខជំនាញនីមួយៗ

បច្ចេកវិទ្យា & IT

វិទ្យាសាស្ត្រកុំព្យូទ័រ & សូហ្វវែរ (Computer Science)

មាគ៌ាពីសិស្សវិទ្យាល័យឆ្ពោះទៅកាន់វិស្វករសូហ្វវែរជាន់ខ្ពស់ (Senior Software Engineer)
១. បញ្ចប់ថ្នាក់វិទ្យាល័យ (High School - Bac II)

ផ្តោតលើមុខវិជ្ជាគណិតវិទ្យា រូបវិទ្យា និងភាសាអង់គ្លេស។ ចាប់ផ្តើមស្វែងយល់ពីកូដមូលដ្ឋានតាមអនឡាញ (HTML, Python)។

២. សិក្សាថ្នាក់បរិញ្ញាបត្រ (Bachelor Degree - ៤ ឆ្នាំ)

សិក្សានៅ RUPP, CADT, ITC, Paragon ឬ AUPP។ សិក្សា Data Structures, Algorithms, Web/Mobile Development និង Database Management។

៣. ការបង្កើតគម្រោងផ្ទាល់ខ្លួន (Portfolio Projects & Hackathons)

ចូលរួមការប្រកួតប្រជែង Hackathon បង្កើតគេហទំព័រ ឬកម្មវិធីទូរស័ព្ទពិតប្រាកដដាក់លើ GitHub ដើម្បីបង្ហាញសមត្ថភាព។

៤. កម្មសិក្សាការងារ (Internship - ៣ ទៅ ៦ ខែ)

ធ្វើការអនុវត្តផ្ទាល់ក្នុងក្រុមហ៊ុនបច្ចេកវិទ្យា ធនាគារ ឬ Start-up ក្នុងស្រុក ដើម្បីស្វែងយល់ពីដំណើរការ Agile Scrum និងការងារជាក្រុម។

៥. Junior Software Developer ($400 - $800/ខែ)

ចាប់ផ្តើមការងារផ្លូវការដំបូង សរសេរកូដ ដោះស្រាយ Bug និងរៀនសូត្រពី Senior Developers។

៦. Senior Software Engineer / Solution Architect ($1,500 - $3,500+/ខែ)

ដឹកនាំក្រុមបច្ចេកទេស រចនាស្ថាបត្យកម្មប្រព័ន្ធខ្នាតធំ (System Architecture) និងធ្វើការជាមួយ Cloud & AI Systems។

ធុរកិច្ច & ហិរញ្ញវត្ថុ

ធនាគារ និងហិរញ្ញវត្ថុ (Banking & Finance)

មាគ៌ាឆ្ពោះទៅកាន់អ្នកវិភាគហិរញ្ញវត្ថុ និងប្រធានគ្រប់គ្រងសាខាធនាគារ
១. បញ្ចប់វិទ្យាល័យ និងចំណេះដឹងគណិតវិទ្យាពាណិជ្ជកម្ម

ពង្រឹងភាសាអង់គ្លេស និងការគិតលេខរហ័ស តាមដានព័ត៌មានសេដ្ឋកិច្ចជាតិ។

២. សិក្សាបរិញ្ញាបត្រធនាគារ ឬគណនេយ្យ (៤ ឆ្នាំ)

សិក្សានៅ NUM, RULE, CamEd ឬ Paragon។ សិក្សាពី Financial Accounting, Credit Analysis និង Financial Markets។

៣. ជំនាញ Excel កម្រិតខ្ពស់ & Financial Modeling

រៀនបង្កើតរូបមន្តហិរញ្ញវត្ថុស្មុគស្មាញ និងទទួលបានវិញ្ញាបនបត្រជំនាញបន្ថែម (ឧទាហរណ៍ ACCA / CAT)។

៤. មន្ត្រីឥណទាន ឬគណនេយ្យករដំបូង (Junior Officer)

វិភាគប្រាក់កម្ចី ត្រួតពិនិត្យរបាយការណ៍ហិរញ្ញវត្ថុ និងដោះស្រាយបញ្ហាអតិថិជន។

៥. ប្រធានគ្រប់គ្រងហិរញ្ញវត្ថុ / ប្រធានសាខា (Branch Manager / CFO)

គ្រប់គ្រងប្រតិបត្តិការហិរញ្ញវត្ថុស្ថាប័នធំៗ ឬដឹកនាំសាខាធនាគារពាណិជ្ជ។

វិស្វកម្ម & សំណង់

វិស្វកម្មសំណង់ស៊ីវិល (Civil Engineering)

មាគ៌ាឆ្ពោះទៅកាន់ប្រធានគម្រោងសាងសង់ និងវិស្វកររចនាសម្ព័ន្ធអគារ
១. គ្រឹះរឹងមាំលើរូបវិទ្យា និងគណិតវិទ្យា

សិស្សពូកែគណនា និងយល់ដឹងពីកម្លាំងមេកានិចនៅវិទ្យាល័យ។

២. សិក្សាសញ្ញាបត្រវិស្វករ (៥ ឆ្នាំនៅ ITC / Paragon)

សិក្សាពីបេតុងអាម៉េ មេកានិចដី រចនាសម្ព័ន្ធដែក និងកម្មវិធីគូរប្លង់ CAD/BIM/Revit។

៣. កម្មសិក្សាការដ្ឋានជាក់ស្តែង (Site Internship)

ចុះការដ្ឋានស្ពាន ផ្លូវថ្នល់ ឬអគារខ្ពស់ៗ រៀនវាស់វែង និងត្រួតពិនិត្យការចាក់បេតុង។

៤. វិស្វករការដ្ឋាន (Site Construction Engineer - $450 - $800)

គ្រប់គ្រងកម្មករ ត្រួតពិនិត្យសុវត្ថិភាពការដ្ឋាន និងអនុវត្តតាមប្លង់បច្ចេកទេស។

៥. ប្រធានគ្រប់គ្រងគម្រោងសាងសង់ (Project Manager / Consultant)

គ្រប់គ្រងគម្រោងហេដ្ឋារចនាសម្ព័ន្ធធំៗរាប់លានដុល្លារ ធានាគុណភាព និងសុវត្ថិភាពស្តង់ដារអន្តរជាតិ។
